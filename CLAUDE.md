# Carwash Booking App

## What we are building

A website for booking carwashes.

- **Drivers** find carwashes on a map and book a time slot.
- **Carwash owners** log in to manage their bookings and services.

## Tech stack

| Tool | What it does in this project |
| --- | --- |
| **Next.js** (with **TypeScript**) | Builds the website: the pages, the buttons, and the server code. TypeScript catches mistakes before the code runs. |
| **Tailwind CSS** | Styles the pages (colors, spacing, layout) using short class names. |
| **Supabase** | The database, plus user login for carwash owners. |
| **Leaflet** with **OpenStreetMap** | Shows the map and the carwash locations. Free, no API key needed. |
| **Vercel** | Puts the website online so anyone can visit it. |

Do not add other tools or libraries unless they are really needed. If one is needed, ask first and explain why.

## Rules for Claude

The person working on this project is a complete beginner learning to code.

1. **Explain every step in simple language.**
   - Before doing something, say what you will do and why.
   - Avoid jargon. If you must use a technical word, explain it in one short sentence.
   - When you ask the user to run a command, explain what it does.
2. **Keep the code simple.**
   - Choose the simplest approach that works, even if it is not the most clever one.
   - Use small files and clear, descriptive names.
   - Add short comments that explain what the code does.
   - Avoid advanced patterns and extra layers of abstraction.
3. **Go one small step at a time.** Build only what was asked, then stop so the user can check and understand it.
